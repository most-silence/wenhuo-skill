# 素材线隔离（isolation）

多源对象（人 + 他推荐的书 + 他的音频……）必须分线，**永不互染**。
起点往往是一条用户指令：「不同来源的认知会不一样，先互不干扰。」

## 为什么要隔离

**① 张冠李戴（最危险）**：书里的阈值流进人物 Skill，产生「听起来合理、实际错误」的回答——
「他认为止损 10%」（书里是 10%，他说的是 5%）。用户看不出来，因为两个数字都真实存在过。

**② 体系自相矛盾**：来源之间本来就互相对立（不同书/不同人方法冲突是常态）。抹平 = 造假。

**③ 归因失效**：混源文档里「他说过 X」无法回溯到素材；回滚、验证、对账全部失灵。

## 规则（四条）

| # | 规则 |
|---|---|
| 1 | 每条线一个目录（`sources/01-视频/`、`02-书籍/`、`03-音频/`……），产出物各线一份，**永不合并成混源文档** |
| 2 | 任何文档的每个结论，引文行号必须落在**本线**素材内 |
| 3 | 跨线引用只许出现在比对文档里，且显式标注「桥接」；冲突两边都保留 |
| 4 | 发布/交付前跑越线检查：grep 各线专属术语在其他线产物中的命中数，期望 0（边界声明、桥接标注除外） |

## 比对文档怎么写

逐条判定来源关系四分类：**A 重复**（两线都讲过，无增量）/ **B 新增**（仅一线有）/
**C 冲突**（两线说法矛盾，**不裁决，保留双方 + 各自引文**）/ **D 细化**（一线是另一线的用法展开）。

C 类是金矿：同一人说透的东西在哪个场合变薄了，两套体系的边界就在哪里。

## 与「存真」原则的关系

隔离不是洁癖，是让**每个结论带得出身**。蒸馏产物的可信度 = 每条引文可回溯到唯一素材线；
做不到这一点，Phase 4 的所有验证都是在给一锅浑水打分。
