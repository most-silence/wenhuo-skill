# 盲评协议（paired 三向 + 棘轮）

**为什么必须盲评**：LLM 自评准确率仅 46.4%（SkillLens 实证）。自己改自己评 = 没有评。

## 评委纪律

- 评委 = **独立子 Agent**，每轮换新，不复用（防锚定）
- N = 3（奇数多数决）
- 评委上下文：只见题目 + 匿名作答，不见版本号、不见改动说明
- 打分只凭质量，不打「进步分」——进步感来自对比，不来自打分者的善意

## paired 三向对比

同一道题，三份作答：

| 份 | 来源 |
|---|---|
| 旧版 | 上一版本 `outputs/` 存档 |
| 上次新版 | 上个迭代 `outputs/` 存档（若有） |
| 本次新版 | 本轮构建后现场作答 |

判定：**本次 ≥ 上次 → keep；否则 revert。** 棘轮只进不退。
作答全部存 `outputs/<版本>/`，**删除存档 = 摧毁基线**。

## 题库构成（每版重编，模板固定）

| 类 | 内容 | 数量 |
|---|---|---|
| A 已知立场题 | 对象公开表态过的问题，验证方向一致 | ≥3 |
| B 边缘题 | 对象未讨论但与其体系相关，验证「推断+不确定」句式 | ≥3 |
| C 风格题 | 闲聊/情绪/极端场景，六维打分（口吻/术语/确定性/结构/情绪/黑话） | ≥20（长答） |
| D 陷阱题 | 通用道理诱饵（「别人恐惧我贪婪」类），验证 V3 排他性没有失守 | ≥2 |
| E 盲区题 | 三类非主路径各 ≥3：情绪疏导 / 多轮追问更正 / 极端场景 | ≥9 |

A 类答案必须来自素材原话整理（带行号），不是构建者代笔——**标准答案错了，整轮验证就作废**（真实事故：v1 题库的期望答案本身是漏读素材造成的假边界，v2 才修正）。

## 六维评分卡（C 类）

每维 0–10：口吻还原 / 术语正确 / 确定性档位 / 结构习惯 / 情绪温度 / 黑话密度。
总分 = 六维均值；记录每题分数与评语进 `outputs/`，供下一轮对比时定位退化点。
