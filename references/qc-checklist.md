## Q10 详解

真实事故类型：跳过长素材 / 只检索术语不检索口语 → 把「有完整答案」误判成「诚实边界」。**假边界比编造更隐蔽，因为读者无从起疑。**

说「他没讲过 X」之前，检索四类词：

1. **术语**：X 的教科书说法（例：财报、止损）
2. **大白话**：他自己会怎么说 X（例：这公司值多少钱、亏了就卖）
3. **近义词**：X 的替代说法（例：底细、调研）
4. **场景词**：讲 X 场景必然出现的词（例：算清楚、钱够不够）

并且：长素材全文分段读完，「看起来像重复」不许跳。**检索记录留在 candidates/，写进审计链。**

## Q11 详解

真实事故类型：三个数字都真实来自原文，但分属不同章节/不同概念，压进一张表后**数学上不成立**（止损 10% + 止盈 20% 配成「1:3」）。单个数字没人怀疑，错的是**被加进去的关系**，而错误关系会直接生成可验算为假的建议。

规则：

1. 同产物内所有数字互相验算
2. 跨章节/跨来源数字，先确认属于同一公式再并表
3. 见「A + B + C」并列，先问：同一层级吗
4. 凡「比例/倍数」表述，给算例并手算一遍
